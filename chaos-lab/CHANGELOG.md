# Changelog

## [1.0.0] - 2026-10-09

### Added

- Docker Compose startup with an automatically configured sandbox and the real Tumult 2.22.0 engine.
- Four guided lessons: slow responses, HTTP failures, unavailable cache, and database timeout.
- Baseline, fault, and recovery measurements, bounded faults, explicit stop, and recovery after an interrupted run.
- Saved run history and downloads for evidence, experiment definitions, and native Tumult journals.
- Optional read-only tutoring through OpenAI, Claude, or local/cloud Ollama with session-scoped credentials.
- Browser learning guide, provider setup instructions, development checks, and documented acceptance results.
