Fault domains

One experiment per domain. Each injects a real fault, then verifies recovery — a passing run is a resilience result, not a smoke-test tick. Run one, then follow its trace link.

Safety guardrail

Not every run should finish. This experiment arms an auto-halt guard that watches demo-app during a database outage and pulls the run — running rollback — the instant it turns unhealthy. Expected outcome: Halted, not Completed.
