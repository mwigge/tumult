What you get

Chaos testing is one source of evidence among several.

Collect

Many kinds of evidence

Chaos experiments, load tests, telemetry from your services, entity events and manual records of exercises.

Author & run

Pick a fault, run it

Choose from 92 actions in 16 plugins, for databases, Kafka, containers, Kubernetes, clouds, networks, hosts and clocks. A wizard writes the experiment file.

Govern

Approvals, stop and audit

Every run gets a risk tier, T0 to T3. Risky runs wait for a second person. Two clicks stop everything. Every action goes into an audit trail that shows any change.

Store

One lake

The daemon takes in traces, metrics and logs over OTLP and OTel-Arrow and keeps them in one DuckDB database. Setup guide.

Score

Resilience, scores and DORA

Ranked risks without running a fault. Scores per team and company. A DORA score that shows what evidence exists. It does not say that you comply.

Judge

Verdicts and a CI gate

Met, breached or not enough data, for each objective. Version against version for performance. tumult gate gives pass, warn or fail to a pipeline.

Forecast

Forecasts and impact

The expected range of a metric, how far a fault pushed it, and how long it took to come back. Works offline.

See it whole

Star Map

The Star Map shows organisation, systems, services and workloads as one graph. Colour it by evidence, risk or telemetry quality.

Prove it

Reports

PDF reports for management, audit and the team. Evidence mapped to DORA, NIS2, ISO 27001, SOC 2 and more. Reports summarise evidence; they do not certify compliance.

Close the loop

AI agents

40 MCP tools let an agent run experiments, query results and suggest the next test. Tumult can also inject faults into AI agents themselves.

Built to run anywhere

Single binary

The daemon holds the lake, the schedulers and the web UI in one file. The CLI is another. Built for macOS and Linux.

Native OpenTelemetry

Every step of a run is a span. Send it to SigNoz, Jaeger or any OTLP backend. Logs are structured JSON.

Memory safe

Safe Rust, with six small unsafe blocks, all for child processes. Strict lints and a dependency audit on every commit.

GameDays

Run a group of experiments as one scored campaign, with one command.

Docker images

Ready on GHCR. No Rust needed: docker pull ghcr.io/mwigge/tumult.

Works with your stack

An OpenTelemetry Collector in front, SigNoz or Grafana behind. No custom build.
